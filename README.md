# My private space

A small GitHub Pages app using Supabase email/password authentication and a personal notes table.

## Supabase setup

1. In Supabase, enable **Authentication → Providers → Email**.
2. In **Authentication → URL Configuration**, add your GitHub Pages site URL to the allowed redirect URLs. For this repository, it will be `https://harsha0818.github.io/Hr/` after Pages is enabled.
3. In **SQL Editor**, run:

```sql
create table if not exists public.private_data (
  id bigint generated by default as identity primary key,
  owner_id uuid not null references auth.users(id) on delete cascade,
  content text not null,
  created_at timestamptz not null default now()
);

alter table public.private_data enable row level security;

drop policy if exists "Owner can read" on public.private_data;
drop policy if exists "Owner can insert" on public.private_data;
drop policy if exists "Owner can update" on public.private_data;
drop policy if exists "Owner can delete" on public.private_data;

create policy "Owner can read" on public.private_data
  for select to authenticated using ((select auth.uid()) = owner_id);
create policy "Owner can insert" on public.private_data
  for insert to authenticated with check ((select auth.uid()) = owner_id);
create policy "Owner can update" on public.private_data
  for update to authenticated using ((select auth.uid()) = owner_id)
  with check ((select auth.uid()) = owner_id);
create policy "Owner can delete" on public.private_data
  for delete to authenticated using ((select auth.uid()) = owner_id);
```

4. Open **Authentication → Users** and create your own account, or use the site's create-account form once it is deployed. Confirm the email if Supabase requests it.
5. For a site intended only for you, after creating and confirming your account, disable public sign-ups in Supabase Authentication settings. Keep your account and sign in normally. Row-level security ensures each signed-in account can access only rows whose `owner_id` is its own user ID.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. The site should appear at `https://harsha0818.github.io/Hr/`. It may take a few minutes to publish.

The Supabase URL and publishable key in `index.html` are client-side values. Never add a Supabase `service_role` or secret key to this repository. Do not commit passwords or user data.
